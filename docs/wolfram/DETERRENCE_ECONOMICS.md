## The Deterrence Formula

### Core Equation

```
D = K × C × P

Where:
D = Deterrence effectiveness
K = Adversary knowledge of defenses (0-1 scale)
C = Cost of attack ($millions)
P = Probability of losing (0-1 scale)
```

### Traditional Security Model (Hidden Defenses)

```
K = 0.3   (Adversary has limited knowledge)
C = $1M   (Estimated attack cost, mostly guessed)

────────────────────────────────────────
D = 0.3 × $1M × 0.5 = $150,000 deterrence
```

**Result**: Weak deterrent. Attacker may try anyway.

```
K = 1.0   (Adversary has COMPLETE knowledge)
C = $86M  (Calculated minimum attack cost)
P = 0.99  (Near-certain loss based on known defenses)
────────────────────────────────────────
D = 1.0 × $86M × 0.99 = $85,140,000 deterrence
```
