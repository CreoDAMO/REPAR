### Step 3: Register as Guardian

**Once your node is running**:

1. Visit: https://guardians.aequitas.zone
2. Connect wallet
3. Verify node operation
4. Choose Guardian tier
5. Receive Guardian NFT

**Or via CLI**:
```bash
aequitasd tx guardian register \
  --node-id $(aequitasd tendermint show-node-id) \
  --tier silver \
  --from my-wallet
```

## Frequently Asked Questions

### Do I need technical skills?
**Mobile**: No technical skills required  
**Home/RPi**: Basic command line helpful  
**Cloud**: Some cloud experience helpful

### How much does it cost?
**Mobile**: $0  
**Home/RPi**: $5-10/month electricity + $150 hardware (one-time)  
**Cloud**: $28-40/month

### Can I lose money?
No. You never stake or lock REPAR. Worst case: You stop earning rewards if node goes offline.

### What if my node goes offline?
Your Guardian status is paused until you bring it back online. No penalties, just no rewards during downtime.

### Can I upgrade tiers?
Yes! Start with mobile, upgrade to home validator, then cloud if you want.

### How are rewards calculated?
Based on uptime, tier, and network participation. Full transparency on-chain.

### Can I run multiple nodes?
Yes! Many Guardians run multiple nodes across different locations.
