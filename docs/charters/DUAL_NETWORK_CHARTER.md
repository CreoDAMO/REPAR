- ⚠️ PRODUCTION - IRREVERSIBLE

### B. Validator Onboarding

**Testnet**: Self-service onboarding
- Run init script
- Request test tokens from faucet
- Start validating

**Mainnet**: Coordinated genesis or upgrade
- Secure validator key generation (HSM recommended)
- Minimum 10,000 REPAR stake
- Coordination with existing validators
- 48-hour notice to community

### C. Upgrade Coordination

Both networks follow:
1. Proposal submitted to DAO
2. Voting period (2 days testnet, 14 days mainnet)
3. If approved, upgrade height selected
4. Validators prepare new binary
5. Network halts at upgrade height
6. Validators restart with new binary
7. Network resumes automatically
