2. **Unescaped special characters** in the JSON

## Key Changes

1. **Removed quotes from EOF marker**: `<< EOF` not `<< 'EOF'`
2. **Fixed indentation**: All JSON at column 0 inside heredoc
3. **Removed backslash escapes**: Not needed in unquoted heredoc
4. **Simplified structure**: Clean JSON without YAML special chars

---

## Why This Fixes It

### Before (INCORRECT):
```yaml
cat > file << 'EOF'
{
  "key": "value"
}
EOF
```
**Problem:** The `'EOF'` quotes prevent variable expansion and can cause YAML parsing issues.

### After (CORRECT):
```yaml
cat > file << EOF
{
  "key": "value"
}
EOF
```
**Solution:** Unquoted `EOF` allows proper heredoc processing in YAML.
