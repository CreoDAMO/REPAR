### Issue #2: Keplr Registry PR - Logo Path Variable Expansion

**Error Context:**
```bash
if [ -f $GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png ]; then
  cp $GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png images/aequitas/chain.png
```

**Root Cause:** Missing quotes around `$GITHUB_WORKSPACE` can cause path expansion issues in some shells.

**Workflow Fix Required:** Add quotes and improve fallback logic.

**Location in Workflow:** 
- Job: `keplr-registry-pr`
- Step: `Create chain configuration`
- Lines: ~2340-2380

**Find:**
```yaml
if [ -f $GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png ]; then
  cp $GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png images/aequitas/chain.png
```

**Replace with:**
```yaml
# Logo exists at multiple locations, try all with proper quoting
LOGO_FOUND=false

# Location 1: Primary logo directory
if [ -f "$GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png" ]; then
  cp "$GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png" images/aequitas/chain.png
  echo "✅ Logo copied from logo/REPAR_Coin_Logo.png"
  LOGO_FOUND=true
# Location 2: Frontend assets
elif [ -f "$GITHUB_WORKSPACE/frontend/public/assets/REPAR_Coin_Logo.png" ]; then
  cp "$GITHUB_WORKSPACE/frontend/public/assets/REPAR_Coin_Logo.png" images/aequitas/chain.png
  echo "✅ Logo copied from frontend/public/assets/REPAR_Coin_Logo.png"
  LOGO_FOUND=true
# Location 3: SVG fallback (convert to PNG)
elif [ -f "$GITHUB_WORKSPACE/frontend/public/assets/repar-logo.svg" ]; then
  echo "⚠️ PNG not found, converting SVG..."
  # Install ImageMagick if needed
  if ! command -v convert &> /dev/null; then
    sudo apt-get update && sudo apt-get install -y imagemagick
  fi
  convert -resize 256x256 -background none \
    "$GITHUB_WORKSPACE/frontend/public/assets/repar-logo.svg" \
    images/aequitas/chain.png
  echo "✅ Logo converted from SVG"
  LOGO_FOUND=true
fi

# Verify logo was found
if [ "$LOGO_FOUND" = false ]; then
  echo "❌ ERROR: Logo not found in any location"
  echo "Searched locations:"
  echo "  - $GITHUB_WORKSPACE/logo/REPAR_Coin_Logo.png"
  echo "  - $GITHUB_WORKSPACE/frontend/public/assets/REPAR_Coin_Logo.png"
  echo "  - $GITHUB_WORKSPACE/frontend/public/assets/repar-logo.svg"
  ls -la "$GITHUB_WORKSPACE/logo/" || echo "  logo/ directory not found"
  exit 1
fi

# Verify copied file size
LOGO_SIZE=$(wc -c < images/aequitas/chain.png | tr -d ' ')
echo "Logo size: $LOGO_SIZE bytes"
if [ "$LOGO_SIZE" -lt 1000 ]; then
  echo "❌ ERROR: Logo file too small ($LOGO_SIZE bytes)"
  exit 1
fi
```
