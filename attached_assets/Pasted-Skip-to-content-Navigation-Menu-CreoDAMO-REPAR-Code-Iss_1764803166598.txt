Aequitas Zone Blockchain v1.0.0
Aequitas Zone Blockchain Binary
Pre-built blockchain binary for deployment to production servers.

What's Included:
aequitasd - Aequitas Zone blockchain binary (152MB uncompressed)
Built with Go 1.23.3
Cosmos SDK v0.50.14
CometBFT consensus
Download & Install:
# Download binary
wget https://github.com/CreoDAMO/REPAR/releases/download/v1.0.0-blockchain/aequitasd-v1.0.0-linux-amd64.gz

# Extract
gunzip aequitasd-v1.0.0-linux-amd64.gz

# Install
chmod +x aequitasd-v1.0.0-linux-amd64
sudo mv aequitasd-v1.0.0-linux-amd64 /usr/local/bin/aequitasd

# Verify
aequitasd version
Deploy to DigitalOcean:
After installing the binary, initialize and start the blockchain:

# Initialize Mainnet
aequitasd init validator-mainnet --chain-id aequitas-1
wget https://raw.githubusercontent.com/CreoDAMO/REPAR/main/chain-config/mainnet/genesis-mainnet.json
mv genesis-mainnet.json ~/.aequitas/config/genesis.json

# Start node
aequitasd start
