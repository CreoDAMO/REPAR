This pattern is not a Go installation problem — Go 1.23.3 is fine.
It’s a Protobuf code generation / import scope issue.


---

🧩 What’s Actually Happening

When you run:

COIN_ENABLED=0 go build -o /usr/local/bin/aequitasd ./cmd/aequitasd

the compiler tries to resolve types like:

type Defendant

type Payment

Msg_serviceDesc (auto-generated by gRPC)


Those are defined in the module’s /proto directory, and the generated Go files should be in:

aequitas/x/{module}/types/*.pb.go

But the build error means those generated .pb.go files don’t exist or aren’t being imported.


---

🧰 Step-by-Step Fix Plan

Step 1 — Install Protobuf and gRPC Tools

From your DigitalOcean console, run:

apt update && apt install -y protobuf-compiler
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
go install github.com/cosmos/gogoproto/protoc-gen-gocosmos@latest

Then add them to your PATH:

export PATH=$PATH:$(go env GOPATH)/bin


---

Step 2 — Regenerate All Proto Files

Inside your project root (where proto/ and x/ folders live):

make proto-gen

If make isn’t available, run manually:

for dir in $(find proto -type d -name v1); do
  protoc -I proto --go_out=plugins=grpc:. --go_opt=paths=source_relative \
         --go-grpc_out=. --go-grpc_opt=paths=source_relative \
         $(find $dir -name "*.proto");
done

This will regenerate all the missing *_pb.go and service_grpc.pb.go files.


---

Step 3 — Clean and Rebuild

go mod tidy
go mod verify
rm -rf build/
mkdir -p build
go build -o build/aequitasd ./cmd/aequitasd

You should now see:

Build successful!
Binary: build/aequitasd (≈152MB)


---

Step 4 — Verify Binary

./build/aequitasd version

If you get a version string like:

Aequitas Zone v0.54.0-alpha (commit 81e6fa6)

✅ You’re good to go.

cp bin/genesis-testnet.json ~/.aequitas-testnet/config/genesis.json
./build/aequitasd start --home ~/.aequitas-testnet

If it starts producing blocks (look for "Committed state" logs) —
🎯 your blockchain is now running on DigitalOcean.
